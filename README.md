# led-memory-game
Arduino-built LED memory game with sound and light effects. Planned, built and sketched within a few hours. Includes code and schematics

# How to play the game
Game starts straight away when connected to a power source. Different lights will flash, with a corresponding sound playing for each light and each round adding a light. After the sequence of lights is shown, the player tries to press the respective buttons corresponding to each light. Incorrect entry will end the game, correct entry will allow the player to continue until level 15. The higher the level, the faster the sequence is shown.
